Selection Sort luôn tìm phần tử nhỏ nhất trong phần chưa sắp xếp rồi đổi chỗ với phần tử đầu tiên của đoạn đó.
Giả sử mảng có n phần tử.

Best (đã sắp xếp)
so lan so sanh n(n−1)/2
so lan swap 0 (hoặc n−1 nếu luôn swap)
do phuc tap O(n²)

Average (ngẫu nhiên)
so lan so sanh(n−1)/2
so lan swap Khoảng n−1
O(n²)

Worst (sắp xếp ngược)
so lan so n(n−1)/2
so lan swap n−1
O(n²)


Số so sánh luôn là n(n−1)/2 = O(n²) vì mỗi vòng đều phải tìm phần tử nhỏ nhất.
